# lofight
那些被廣告氣死的遊戲我做給你玩

## 人海攻城

HTML5 canvas 遊戲，React + Vite。砲台射出士兵，穿過倍率門、打破道具門，沿山路攻向紅軍與魔王。

### 開發

```
npm install
npm run dev      # 本機開發
npm run build    # 輸出 dist/index.html（單檔）
```

### 部署

Render 靜態網站，設定在 `render.yaml`（Blueprint）。推到 `main` 就會自動 build 與部署。
