## 行為分類與句型骨架

### Creation（建立guest身分、開局、第三方登入首次建帳）

- When：`When <操作>：`（接 Data Table）
- Then（成功）：`Then 操作成功` + States Verify（`Then <實體> 應為：`）＋ Result Verifier（`Then 回應資料應為：`）
- Then（失敗）：`Then 操作失敗，錯誤代碼為 "<code>"`（Example 上方加 `@error:<code>`）

### Mutation（修改暱稱、換發、登出、結算、購買、合併）

- When：`When <操作>：`（接 Data Table）；同時送出用 `When 同時送出以下購買：`
- Then（成功）：`Then 操作成功` + States Verify（金幣餘額、庫存、帳本、run、排行榜、事件、權杖撤銷）
- Then（失敗）：同 Creation；狀態不變以 States Verify 斷言

### Query（查詢玩家進度、錢包、帳本、商店、庫存、排行榜、合併預覽、事件統計）

- When：`When <查詢>` 或 `When <查詢>：`（接 Data Table）
- Then：`Then 回應資料應為：`（單筆）／`Then 回應中的 "<listField>" 應為：`（列表，依序比對）

### Diagnostic（驗證存取權杖 @cross）

- 以任一受保護操作（查詢玩家進度）為載體，Then 失敗碼 401xxx

## 共用契約

### Postcondition 模式

- 金幣異動一律「錢包餘額 + 帳本一筆（含 coinsAfter）」成對驗證（結算、購買、合併、廣告獎勵）
- 附帶紀錄：瀏覽商店、購買buff、領取廣告獎勵 成功各寫一筆事件；失敗不寫；發放賽季獎勵每筆受獎寫一筆 SEASON_REWARD 事件
- 賽季獎勵（CHANGE 2026-11-03）：每（賽季, 榜別）一筆發放記錄＋受獎者各「錢包 + 帳本 SEASON_REWARD（含賽季、榜別、名次）+ 事件」同一交易；無受獎者仍寫記錄（0 人）
- 廣告獎勵（CHANGE 2026-11-02）：帳本 AD_REWARD 一筆含 deviceId、事件 AD_REWARD 一筆含 deviceId；當日次數與冷卻只看本人帳本（合併不沿用，AMB-A2＝b）
- 合併（Google/Apple 登入）：帳本一筆 MERGE_IN、guest isVoided=true、guest 舊權杖 401001
