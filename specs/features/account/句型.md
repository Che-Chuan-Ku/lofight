# account 句型模型

## 實體概述

- **性質**: Aggregate（玩家，含第三方身分、換發權杖子實體）＋ Gateway（Google Identity、Apple 登入服務、預設暱稱產生器、禁用字清單）
- **攜帶狀態**: playerKind、nickname、deviceId、isSilverUnlocked、isVoided、mergedInto、coins（錢包）、第三方身分、換發權杖（expiresAt、revokedAt）
- **Invariant 清單**: device id 唯一且永遠對應同一 guest；同一 (loginProvider, sub) 只對應一個帳號；作廢 guest 不可再取得權杖或被合併；暱稱 1–12 字、非空白、無禁用字；換發權杖撤銷後不可再用

## 測試分析

### 建立guest身分
**等價類**: 新 device id／既有 device id／作廢 guest 的 device id／未提供。**邊界值**: 不適用。**狀態轉移**: 無 guest → 建立；有 guest → 沿用。**組合覆蓋**: 不適用（單參數）。**錯誤推測**: 作廢 guest 復活（GAP-15 推論 → acc003）、重複建立。

### Google登入／Apple登入
**等價類**: token 缺漏／驗證失敗／有效；攜帶 guest 與否；目標帳號新建／既有。**邊界值**: 不適用。**狀態轉移**: guest 未作廢 → 作廢；帳號不存在 → 建立。**組合覆蓋**: (攜帶 guest) × (帳號新建/既有)。**錯誤推測**: 第三方姓名寫入暱稱、已作廢 guest 二次合併、Apple 隱藏信箱變動。合併時新帳號暱稱一律系統預設（Rule 未列暱稱為合併項目）。
