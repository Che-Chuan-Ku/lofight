# leaderboard 句型模型

## 實體概述

- **性質**: Aggregate（排行榜成績，關聯 run 的 loadout）
- **攜帶狀態**: (boardVersion, tier, 玩家) → isVictory、gameSeconds、settledAt、run
- **Invariant 清單**: 每 (版本, 階層, 玩家) 一筆；排序 勝局在前 → 勝局秒數少 → 敗局秒數多 → settledAt 早；前 15 名；自己 ±2 名
- **設定值**: 目前版本前兩碼（後端設定檔）

## 操作清單

| 操作 | 行為分類 | When Data Table 欄位 | Then Data Table 欄位 | Violation Types |
|------|---------|---------------------|---------------------|-----------------|
| 查詢排行榜 | Query | tier、boardVersion（選填） | boardVersion、tier；entries／myRank／neighbors：rank、nickname、isVictory、gameSeconds、equippedBuff | 400001、400012（401003 由 @cross） |

## 測試分析

### 查詢排行榜
**等價類**: tier 缺漏／GOLD／BRONZE／SILVER；版本未提供／指定；查詢者有成績／無成績。**邊界值**: 第 15／16 名截斷；名次在榜首（上方不足 2）。**狀態轉移**: 不適用（查詢）。**組合覆蓋**: 排序四鍵同時作用（勝敗 × 秒數 × 同分 settledAt）。**錯誤推測**: 以暱稱去重誤合併「勇者248」、跨階層混榜、舊版本混入。
