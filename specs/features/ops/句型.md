# ops 句型模型

## 實體概述

- **性質**: Aggregate（事件 append-only，唯讀彙總）
- **攜帶狀態**: eventKind（SHOP_VIEW／BUFF_PURCHASE／AD_REWARD／SEASON_REWARD（CHANGE 2026-11-03，AMB-S12＝b））、玩家、isSilverUnlocked、buffItem、paidCoins、deviceId（AD_REWARD）、occurredAt
- **Invariant 清單**: 區間含起不含訖（UTC）；不重複玩家以帳號或 guest id 計；無身分驗證（GAP-13=C，部署層限制）

## 操作清單

| 查詢事件統計 | Query | from、to | eventTotals：eventKind、count、uniquePlayers；purchasesByItem：buffItem、count、totalCoins | 400001、400007 |

## 測試分析

### 查詢事件統計
**等價類**: from／to 缺漏、起始晚於結束、正常區間、無事件區間。**邊界值**: 起點時間的事件計入、訖點時間的事件不計（00:00 計入、次日 00:00 不計）。**狀態轉移**: 不適用。**組合覆蓋**: 事件類型 × 玩家（不重複計數）。**錯誤推測**: 不重複玩家誤用次數、金幣總額用現價而非事件價。
