# run 句型模型

## 實體概述

- **性質**: Aggregate（run，含逐王紀錄）＋ Gateway（系統時鐘、版本設定、出場秒數門檻、金幣表）
- **攜帶狀態**: tier、equippedBuff、boardVersion、startedAt、runState（OPEN／SETTLED／CHECK_FAILED／ABANDONED）、gameSeconds、isVictory、bossesKilled、deathCause、deathBossSeq、coinsAwarded、settledAt、isSilverNewlyUnlocked
- **Invariant 清單**: run 只能離開 OPEN 一次；bronze 無 buff、silver 至多 1 個；庫存不為負；結算檢查全過才入帳上榜（含 bossKills：序號在階層範圍內、不重複、勝局須全破；任一不符 → gam003＋CHECK_FAILED）；重送已結算 run 冪等
- **設定值（測試以後端預設設定為準）**: bronze 出場秒數 1–7 王 14/28/42/56/70/84/98、第 8 王下限 98（第 7 王之後出場，推論）、第 9 王下限 98（第 8 王擊破後自動進場，CHANGE 2026-11-04 D42）；silver 1–7 王 14/28/42/56/70/84/84（第 7 王下限 84，CHANGE 2026-11-03 AMB-X15＝a）；最後一王擊破秒 ≥ 前一王擊破秒（bronze 第 9 ≥ 第 8、silver 第 7 ≥ 第 6；兩者皆在清單時檢查，INF-X21、D42）；勝利秒數門檻 bronze 98、silver 84（≥，D-09 2026-11-02）；金幣 bronze 1,2,4,8,16,24,36,60,90（合計 241，AMB-N3）、silver 4,8,16,32,64,128,192（AMB-X14＝b）；放棄逾時 24 小時（超過才放棄，恰好 24 小時仍可結算）；silver 解鎖＝首次擊破 bronze 第 9 王（AMB-N2）

## 測試分析

### 開局
**等價類**: tier 缺漏／GOLD／BRONZE／SILVER；buff 0 個／1 個／2 個；庫存 >0／=0。**邊界值**: buff 數 1（通過）與 2（失敗）；庫存 1 → 0。**狀態轉移**: 未解鎖 silver → 拒絕；庫存扣減。**組合覆蓋**: tier × buff 有無。**錯誤推測**: 併發搶扣最後 1 份（BDY-05）、bronze 偷帶 buff。

### 結算對局
**等價類**: 必要參數缺漏（3 種）；run 不存在／他人／CHECK_FAILED／ABANDONED／OPEN；勝／敗；bronze／silver。**邊界值**: 擊破秒數 = 出場秒數（通過）與少 1 秒（失敗）；勝利秒數 = 門檻（通過）與少 1 秒（失敗）；最後一王擊破秒 = 前一王（通過）與少 1 秒（失敗）（silver 7/6、bronze 9/8）；逾時 24h（通過）與 24h+1s（放棄）；伺服器經過 60s 對回報 61s（失敗）；擊破序號 bronze 0／10、silver 8（越界失敗）、bronze 9／silver 7（合法）；勝局王數 bronze 8／silver 6（不足失敗）。**狀態轉移**: OPEN → SETTLED／CHECK_FAILED／ABANDONED；SETTLED 重送冪等。**組合覆蓋**: 排行榜（無既有／較差／較佳／同分）× 版本來源（run vs 設定）。**錯誤推測**: 前端灌金幣（後端自算）、bossKills 重複序號（審核修正：gam003，不靠 DB 唯一索引）、重送重複入帳、首通解鎖遺漏。
