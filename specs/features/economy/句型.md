# economy 句型模型

## 實體概述

- **性質**: Aggregate（錢包、金幣帳本 append-only）
- **攜帶狀態**: coins；帳本 ledgerSource（BOSS_REWARD／MERGE_IN／BUFF_PURCHASE／AD_REWARD）、coinDelta、coinsAfter、bossSeq、buffItem、deviceId（AD_REWARD）、occurredAt；事件（AD_REWARD）
- **Invariant 清單**: coins ≥ 0；帳本只增不改；只回查詢者本人帳本；廣告獎勵當日（UTC）AD_REWARD 筆數 ≤ 5、相鄰兩筆間隔 ≥ 60 秒；入帳＋帳本＋事件同一交易、同一玩家依序處理（鎖錢包列）；被拒不寫任何資料
- **設定值**: 每頁 20 筆；廣告獎勵 200 金幣、每日 5 次、冷卻 60 秒、UTC 日界；發布商 ID 環境變數 ADSENSE_PUBLISHER_ID（皆後端設定，測試以 Given 注入發布商 ID 有無）
