# economy 句型模型

## 實體概述

- **性質**: Aggregate（錢包、金幣帳本 append-only）
- **攜帶狀態**: coins；帳本 ledgerSource（BOSS_REWARD／MERGE_IN／BUFF_PURCHASE／AD_REWARD／SEASON_REWARD）、coinDelta、coinsAfter、bossSeq、buffItem、deviceId（AD_REWARD）、seasonBoardVersion／seasonTier／seasonRank（SEASON_REWARD）、occurredAt；事件（AD_REWARD、SEASON_REWARD）；賽季獎勵發放記錄（boardVersion、tier、recipientCount、totalCoins、settledAt）
- **Invariant 清單**: coins ≥ 0；帳本只增不改；只回查詢者本人帳本；廣告獎勵當日（UTC）AD_REWARD 筆數 ≤ 5、相鄰兩筆間隔 ≥ 60 秒；入帳＋帳本＋事件同一交易、同一玩家依序處理（鎖錢包列）；被拒不寫任何資料；賽季獎勵（CHANGE 2026-11-03）：同一（賽季, 榜別）只有一筆發放記錄、同一玩家同一（賽季, 榜別）最多一筆 SEASON_REWARD 帳本；只結算早於目前賽季且不早於 19.0 的賽季；只發 MEMBER、guest 名次不遞補
- **設定值**: 賽季獎勵名次金幣表 1200／800／400／200／100（前 5 名，2026-11-03 使用者改裁決）、最早發放賽季 19.0（後端設定檔，INF-S1／INF-S11）；目前賽季＝建置版號大.中（AMB-S6＝b，測試以 When 的建置版號注入）；每頁 20 筆；廣告獎勵 200 金幣、每日 5 次、冷卻 60 秒、UTC 日界；發布商 ID 環境變數 ADSENSE_PUBLISHER_ID（皆後端設定，測試以 Given 注入發布商 ID 有無）
